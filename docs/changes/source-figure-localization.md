# 来源图形定位接入统一入口

## Status

implemented

用户批准把既有来源图形定位路线接入统一 CLI，补齐自动回归和流程文档；只使用用户现有书籍验证，不扩大模型或外部样本实验。

## Problem

已验证的原生对象、图注边界及 CV 补全仍分散在绑定单书路径的实验脚本中。几何切开不等于图注配对正确，候选框也不能证明来源内容完整；重复推理和常规逐图审查增加了无效投入。

## Scope

- 增加独立的来源图形处理工站，复用 manifest、scratch、隐藏子进程、来源渲染及现有工站记录，不改变构建或交付的旧入口。
- 以原生图像／绘制对象和独立原生图注为优先证据；布局模型只提供候选，CV 只补位。保持原生彩底、图内独立文字及完整图注身份。
- 将已验证实现参数化；工具与模型路径由显式本机 runtime 配置提供，不依赖实验目录、私人书名或固定主机路径，不自动下载模型或切换引擎。
- 独立执行图注配对和裁切边界完整性检查；歧义、跨界和不支持情况明确进入复核。当前不自动应用未通过语义配对验证的空白分割，不把几何切开当作完成。
- 报告、渲染、提取和原始响应只写作品 scratch；不自动写正式底稿、资产、STATUS 或 OneDrive。
- 复用结果须绑定来源、配置、工具及所选页；不重跑有效同输入推理，不建立新的持久缓存平台。
- 公共测试使用合成最小样例；真实验证限定为既有私人来源，具体书籍与结果只记忽略目录。

## Acceptance Criteria

1. 统一入口能处理任意合法所选页，不再要求固定书名、页数、实验路径或 CUDA 安装位置；非法输入在运行重工具前拒绝。
2. 实际来源调用能够恢复原生完整图形、图内独立说明和侧置图注，并保原生图像矩形及彩底；模型候选与来源事实分别记录。
3. 自动回归覆盖完整性、外来内容、图注身份、多图唯一归属、裁切切线及几何分割不等于配对成功、歧义拒绝、失败恢复、复用失效和无窗口执行；真正的四像素目标损失不得由容差放行。
4. 工站候选不冒称全书或内容验收通过；来源信息不足时保留复核状态，旧命令和既有完成证据不受影响。
5. 首次全量基线、模块增量及冻结后的最终全量通过；仅用现有书籍完成真实统一入口验证，不常规逐图看图。
6. 流程、CLI 契约和实际实现一致，中文 Markdown 格式检查与独立 review 通过，blocking 关闭。

## Result

`source-figures` 已接入统一工站，runtime 显式绑定已有工具和模型；来源提取、原始张量、原行身份、图注字形与候选图均只写 scratch。基础 CLI 不加载重工具依赖，候选始终 `verified=false`，歧义保留 `needs_review`，不自动启用未验证拆分。

逐页推理与后处理分别绑定依赖：选页交集直接复用，后处理修改保留有效 raw；来源、模型或实际输入变化才重推理。复用报告及其内部产物受同一作品临时根约束；裁切检查保原生彩底，并拦截连通目标被切断、图注混入、图号冲突和未证明的文字归属。

冻结后的最终全量为 1,037 通过、5 项条件跳过、363 项 subtest；其中 3 项像素／CV 测试另在配置的实际重 Python 环境全部通过，另外 2 项为既有条件跳过。文档结构、长度和 AutoCorrect 检查通过；详细 runtime／状态契约独立注册，原有文档长度上限不变。

仅以两份用户已有来源的 5 页、6 幅图执行真实入口验证：来源绑定目标零漏损、外来源墨零混入，原生图像矩形和彩底完整，图注逐行／字形身份一致；五页各一次 forward，重算均复用 raw。机器仍保留 3 个候选、3 个复核状态，独立来源检查未将其改成自动通过。四次冻结入口的窗口监听未观察到命令树可见终端弹出；首次两页推理未在监听范围内。

## Review

独立 Terra/max reviewer 完成一次只读复核。发现的独立图例、邻图注、裁切连通性、预处理复用绑定、regionless 归属、原生 clip、图号标点及小面积浅彩底问题均以通用正反例修复；blocking 已关闭。主 Agent 核收实际入口、来源评分、复用等价证据和最终自动结果，不以候选生成或模型置信度代替内容验收。
