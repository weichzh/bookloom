# 最终验收的显式浏览器时间预算

## Status

implemented

按用户对本轮共性流程缺口的持续修复授权实施；不改变默认预算、检查范围或通过条件。

## Problem

独立 browser-qa 已支持有限 timeout，而 finalize 硬编码默认值，调用者无法为持续推进的大型成品声明更长的机器执行预算。已观察到顺序浏览器检查正常推进但超过默认预算；有界 profile 显示延迟期间渲染主线程持续消耗 CPU，不能将短轮询失败直接判为死锁，也没有证据支持缓存或前后台调度修法。

## Scope

仅给 finalize 增加 --browser-timeout SECONDS 和 --browser-page-timeout SECONDS，分别覆盖既有浏览器每模式整体和单页 timeout；默认沿用每模式 600 秒、单页 30 秒。保完整成员、三模式、链接和注释检查。无这两个属性的旧 Python Namespace 调用保持可用，不修改 refresh 或独立 browser-qa 的既有契约。

## Acceptance Criteria

1. CLI 显式正整数预算完整透传至既有 browser-qa；省略时与旧默认完全一致。
2. 非正预算在构建、证据清理和外部写入前失败；不接受无限预算或自动跳过检查。
3. 保旧 programmatic Namespace 和非 EPUB 正式输出；不为它们增加 EPUB 依赖。
4. 模块回归、实际 CLI help 及受影响调用通过；正式成品仍由真实最终矩阵裁决。

## Result

已实现可选参数及旧 Namespace 兼容；局部真实 CLI／参数透传／拒绝顺序／PDF-only 流程回归 35 项与 18 项 subtest 通过，1 项可选真实浏览器测试未启用。冻结后的全项目最终结果为 898 通过、2 跳过、356 项 subtest 通过；两项跳过为当前环境无公式库及未启用的可选真实浏览器测试，其余实际浏览器回归已运行。默认仍为每模式 600 秒；随后在真实大型成品上以显式每模式 1800 秒完成全部三模式，失败项为 0；直接比较实际 EPUB 成员，正文 XHTML 与公式／图像／封面资产未变，仅共享样式和构建时间变化。项目测试与成品验收分别成立。此参数只提供显式有限执行预算，不作为浏览器性能修复。

实际大章节另触发既有 30 秒单页加载超时；已接入显式有限单页预算，38 项回归通过。省略时仍为 30 秒，非正值在载入作品及失效证据前拒绝；旧 Namespace 兼容，实际下游传参及完整三模式门禁保持，不跳过超时章节。

## Review

root 完成实际调用链与性能证据判断，执行者只实现限定参数和测试；root 已读实际最小 diff 和全部新用例，合入并核对默认契约、失败顺序、真实 CLI 和原输出条件。未将延长预算冒称性能提升，未移除任何检查；首次独立兼容 review 已检查真实调用、失败顺序和旧接口，未发现 actionable blocking；复用同候选最终全量，不重复测试。

单页预算接入另经独立 Terra/max reviewer 复核，覆盖旧 Namespace、默认值、参数拒绝顺序、下游传参及完整三模式门禁，无 blocking。此接入与整体预算一同保留，未纳入 SVG 轻量展开的单功能提交。
