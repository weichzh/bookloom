# 公共文档边界与可重复流程实验

## Status

implemented

用户已授权整理公共仓库、总结收尾，并利用已有原生源码持续检验流程及模型／子智能体分工。

## Problem

来源 spine／标题计数完整时，仍可能有大型评注子树未进入翻译输入；局部结构或成品门禁通过不能替代这层来源消费覆盖。

共享变更中混入单书进度、私人交付记录和本机证据路径；忽略来源目录不能保护已复制进公共文档的内容。真实来源可支持流程回归，但未区分版本、覆盖字段和保留样本的比较容易把来源差异或额外人工投入误当方法提升。

## Scope

- 关闭最终回归暴露的陈旧 fixture 与新引入机械 lint；保真实图注、编号、嵌套滚动、脚本依赖及旧调用条件，不为绿灯改正文或削弱断言。复杂来源在翻译前明确大容器与完整子树消费范围。
- 公共 change 只保留通用缺陷机制、接口、适用条件、兼容性、可公开回归及验证结论；单书状态留在私有 STATUS，原始证据留在仓库忽略目录，不删除已有单书事实。
- 公共 ACTIVE 只说明本机可选指针入口，实际批次指针留在忽略目录；公共文档不依赖私有文件存在。沿用单书 STATUS 所有权和旧活动目标校验，不新建状态平台。
- 在既有工作流收敛原生源码优先、版本绑定、任务分工、来源分区及有界实验；复用 pytest、CLI 工站、handoff 和现有批次元数据，不另建评测平台或自动切换模型。
- 在既有文档检查中拒绝公共 change 的具体私有来源／工作区路径、具体本机绝对路径及私人交付回执；保留通用路径占位符、公开工具文档和技术示例。排除已发现的误生系统缓存目录，不删除其内容。

## Acceptance Criteria

1. 当前公共 change 不再承担具体书籍的制作、审校和交付记录，保留各共享变更的技术契约和真实验证强度；不把未运行或局部证据改写为全量通过。
2. 公共文档只提供私有任务记录的通用入口；既有正式入口和活动目标校验保留原条件，兼容已有 book 指针。
3. 来源实验可从只读来源及现有提取方法重建；明确参考字段、未覆盖语义、失败样例、保留确认集、总耗时和已知成本，不凭计数或模型一致性验收。
4. 研究、关键裁决和最终验收由主 Agent 负责；具体处理及测试交给独占分片的新建 Terra/max。实验不阻塞满足原验收条件的书籍交付，不新增整书复审。
5. 修改文档通过 AutoCorrect、既有文档结构及新边界正反回归；不得自动提交或推送。

## Result

30 个既有共享 change 已整理为通用技术记录；具体书籍、私人路径、交付回执和旧 Agent 身份不再承担公共变更事实。公共 ACTIVE 通过可选本机指针衔接既有私有批次，不新增对私有 JSON 的硬性文档校验依赖。旧 Works 状态指针校验原条件保持；增加无 Books／Works／本机状态的公共文档副本回归。

已登记版本化 TeX 与同版配套代码两类私有来源回归入口，并复用既有 OCR／公式并发试验；参考只覆盖其实际字段。新的模型协作对照尚未运行，已限定假设、两种交接方式、完整对象诊断与确认集及成本口径，不阻塞已达标书籍。

当前冻结代码的全项目结果为 **919 通过、2 跳过、356 项 subtest 通过**，已纳入完整表格页点边界及空段尾文本保全。测试进程显式绑定主机上已有的有效 Node，不修改全局 shim。两项跳过分别是当前项目环境未装公式库和未启用的可选真实浏览器用例；其他实际浏览器回归已执行。

此前全量曾为 872 通过、7 失败、2 跳过。7 项失败按实际图注／编号契约、嵌套滚动口、正常脚本入口及依赖补齐 fixture；公开用例改为合成对象，保留真实几何、引用、断行与负例断言，未为绿灯改产品行为。修复后为 878 通过、1 失败、2 跳过；剩余失败来自主机 Node shim 无法启动已安装版本，显式绑定已有可执行文件后闭合。随后完成最小执行预算接口并冻结为 898 项通过的候选；再补齐真实消费暴露的表格页点边界与空段 tail 缺口，形成上述 919 项通过的当前候选。

一次固定十请求的本地管线比较已完成，原始响应全部以 EOS 结束。叙述型 layout 输出补回若干字段，却把生成说明与标签混合，并出现错误尺寸归属；纯文本 OCR 仍漏重复尺寸和部分度数。已据此明确分开消费转录与说明，不采用整图默认替换或模型投票。此结果限定于冻结的任务、来源类别及本机配置；后续模型／子智能体交接对照仍未运行。

实际分片合入还暴露组合缺陷：孤立片段能被 reader／writer 正确解析，但与旧段只隔一个换行时，新标题会变成段内字面文本，原 ID 仍可能存在。已将相邻完整对象的实际 AST 纳入现有合入检查；只修已证接缝，不新增整书复审。恢复真实标题会使自动 ID 漂移，故为新恢复标题设置来源稳定的显式唯一 ID，并逐对象确认既有标题和页导航绑定不变。

原生类名也存在适用边界：行组可能承载年代条目，目标引用也可能已有正确诗行。恢复按完整源对象与实际目标 AST 分区，不强制所有同类容器变成诗歌。分行只改变相邻 Str 的分块时可作同级串接比较；逐字、每个 Space 及完整注释／强调／Span 属性仍保持，删字、删 Space 和错注身份的负例均拒绝。真实消费进一步表明：这种内联守恒仍会放行已有诗行被合并，或引语引导被移进引文；因此旧译行和叙述／引文角色必须另行保护，撤销容器一对一计数的实施假设。

原表图身份和目标 Table 的完整 AST 保持，仍不能证明格值与来源相同。专项字段比较发现漏项、错年数及连续时间轴被误当离散行的关系缺陷；表图盘点必须覆盖全部原生 img 及上下文，不以资源命名白名单漏掉已重制成原生表的来源；已明确重排要保条目年代、原分组与顺序，不能按图上坐标构造假的同行日期。不可离散化的空间／字体表达保原图，中文对照仍须完整消费应译字段。

最终排版需独立于结构变换核定。格式器会调整中英间隔，并可能因标题括号变化而改变自动 ID；本次逐项核准有限的排版差异，显式保原标题 ID，并检查既有诗行与引用／页导航身份。结构变换的逐字／空格守恒断言仍按其原条件执行，不用排版许可放行任意丢字、丢行或丢空格。

现有译稿还出现将原注异读代入正文、以其他读法替换来源专名的成类差异；已明确分别保护正文和注释的读法身份。此处记录观察到的缺陷类型，不据此认定模型记忆为已证原因；具体单书修复仍留私有记录。

新增／未匹配的 86 项 lint 均闭合，剩余 49 项与 HEAD 同一源对象及原断言完全对应，仍是既有技术债务，未宣称全库 lint 通过。机械修正不改变语义；公开 typing 别名和渲染／回调恢复边界用 6 处局部豁免说明保留，不为 lint 缩窄异常处理或修改接口。

## Review

主 Agent 已读全部候选及实际差异，保留真实契约、负要求和局部证据强度。审查发现将公共 ACTIVE 直接硬绑私有批次会使干净克隆的文档检查失败，故不采用该扩展，保原接口并将运行指针留在本机。冻结回归的独立执行者给出实际失败后，主 Agent 逐项核对 fixture 与原契约并合入；最终全量、环境单项修复及文档边界正反证据按实际强度记录。
