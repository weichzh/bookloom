# 数学标题的双表示导航核验

## Status

implemented

## Problem

受控目录静态门禁把来源标题中的 TeX 与已存在的可读目录文本直接比较：例如正文标题与 SVG alt 保留 `\mathcal L_A`，目录按既有映射显示 `L_A`，导致真实内容完整仍被误拒。

## Scope

复用并集中已有 replace_navigation_formula_images 中的闭合公式文本映射，不增加新字体／脚本的宽松等价，不把 TeX 写成导航乱码。分别严格核两层：导航标签按来源标题派生相同的可读文本；正文真实标题仍按来源原 TeX／原图 alt 完整核验，字体、分组、数字及脚本不因导航转换而放宽。章节层级、ID、实际落点、源注号及普通图片替代文本不变。

缺省纯 API 和既有调用保旧行为；仅受控生产目录显式使用双表示。源码／正文／SVG alt 不改成目录简写，不删检查、不加书名／章节跳过项，不维护第二份手写目录，不新增 OCR 或数学渲染平台。NCX 兼容层与唯一 nav 同源派生，原标题 noteref 清理保持身份。

## Acceptance Criteria

1. 既有确定公式映射只有一个事实源，未知反斜杠公式仍拒绝；普通 Code、数字、上下标、native Image 及 noteref 原行为保持。
2. 可读数学 nav 与完整 TeX 正文标题分别匹配来源；错误 nav 符号／数字／脚本、错误正文字体／TeX／alt、ID／层级／落点漂移均拒绝，不能因同一转换函数把两层一起简化而假通过。
3. 既有 API 缺省仍接受原有原文标签调用；新参数或内部表达必须显式、可兼容，正常非数学目录无变化。
4. 在最小真实 Pandoc 夹具和保存的原始 EPUB 静态对象上定位标签差异；修复期间只跑相关静态／导航模块，不反复用全量 finalize 逐条发现静态失败。
5. 核实现及一次独立 review；真实消费者检查受影响成员后，再由冻结候选做最终全量。

## Result

已合入显式 navigation_math_labels 双表示；既有闭合映射集中为单一事实源。正文原始数学对象与文本位置独立核验；NCX 在构建与受控 Markdown QA 均同实际 nav 严格绑定，缺省 API 兼容。候选原始测试 110 项及 51 subtests 通过；两项 blocking 修复后新增模块 62 项、相关 69 项及 44 subtests 和隔离写出器 seam 通过；正式入口定点 13 项通过、49 项未选。

保存的真实旧中间包用于 nav／NCX 和来源标题／正文的静态对照。普通 Image 的 Math 型 alt 原被导航映射误处理，修复后 5 项定点通过，普通图片 alt 保持字面。真实修正消费者通过标准构建、完整受控目录／正文门禁及三模式最终全量检查；这是该输入的实际结果，不推广到其他来源。

## Review

独立 review 发现两项 blocking：公式 alt 少字可由相邻普通文字拼回，整标题字符串相同仍假通过；NCX 错指已存在的另一标题时不被唯一 nav 门禁识别。两项均以最小反例修复并核对正式调用 seam，blocking 关闭。
