# 自动化优先的渐进式验收

## Status

implemented

## Problem

逐页把原图交给模型复核耗时且高 token，旧硬规则把它设为完成前提；目标级 refresh 仍对单个 EPUB 执行全量浏览器矩阵，章节交接 v1 又要求全部来源视觉声明。测试数量、链接闭合或图像抽样均不足以单独证明内容正确。

## Scope

- 同步规则和工作流：来源仍是事实依据，来源绑定、结构／内容不变量与自动检查作为常规证据；失败、歧义及新视觉设计才做定点视觉工作。
- 首次候选全量自动基线，中间按章节／对象及变更依赖执行适用测试，冻结候选最后一次全量；包结构、唯一导航及跨文件引用等全局约束仍检查。
- browser-qa 和 EPUB refresh 支持可重复的 --member，使用精确包内 XHTML 名称；未知／空／越界选择失败，默认调用仍检查全部。三种模式使用同一选择，结果记录完整清单、已选与未选；局部结果不能成为 final 证据。
- 普通运行只为失败页保留诊断截图；需要设计或定点诊断时可显式选择 representative 截图策略。
- 章节交接增加 v2 自动核验声明，保 v1 原有语义和无交接包旧调用契约；v2 覆盖完整来源与明确验证项，视觉异常清单仅列实际看过的范围。
- 不新建自动缓存／依赖调度平台；模块选择依据实际 diff 和引用关系，改共享 CSS、字体或检查器要扩大到全部受影响单元。源内容、译义和封面设计不改成仅凭计数裁决。

## Acceptance Criteria

1. 当前操作规则不再要求逐页审图；图片仅用于异常诊断、消除歧义和必要设计，并将可表达的缺陷转成有明确适用条件及正反样例的回归。
2. 两个命令可只选部分 XHTML，保三模式、资源及实际链接检查；报告明确未覆盖范围。非法选择不可静默为空通过，finalize 不接受局部回执。
3. 默认全量、旧 v1 交接和无声明旧用法保持可用；v2 不要求全来源视觉声明，但缺来源覆盖、失败验证或未解决问题仍阻断。
4. 测试证明局部选择与全量最后门禁、失败截图策略、v1／v2 兼容，使用可合成小样本而非重新审查已交付书籍。
5. 触碰的中文 Markdown 格式与结构检查通过，实际 diff 无范围外重构；剩余能力缺口如实登记，不把政策当作已实现参数。

## 采用已有工具

- [pytest 测试选择](https://docs.pytest.org/en/stable/how-to/usage.html)：按文件、node ID 或 -k 运行已有模块；[失败重跑](https://docs.pytest.org/en/stable/how-to/cache.html)用 --lf，不能拿上次失败清单代替本次变更依赖。
- [EPUBCheck 官方 CLI](https://www.w3.org/publishing/epubcheck/docs/cli/)支持 xhtml／nav／opf／svg 单文档模式与 JSON 报告。本机固定 jar 实测：正常 XHTML 零问题，破损 XHTML 返回 fatal；局部规范诊断可直接复用，不自写替代验证器。全包引用与终态仍用全包检查。
- [Pandoc AST／filter](https://pandoc.org/filters.html)及项目现有语义检查用于结构和内容对象，不用正则重建解析器；浏览器继续复用 agent-browser／现有 DOM runner。

## Result

规则已同步到 AGENTS、PROTOCOL、TRANSLATION、EPUB 和 CONTRACTS。browser-qa 与 EPUB refresh 已支持可重复 --member；不传参数仍全量。同一选择覆盖三种读者模式，保留完整解包及跨未选 XHTML 的链接／noteref 验证。结果分别记录完整清单、已选／未选和实际执行／未执行；空／重复／未知选择失败。最终回执按实际包清单拒绝 selected 或不完整结果，旧无 coverage 的完整回执仍兼容。截图默认仅失败，显式 representative 与任意非负截图数量的旧用法保留。

交接 v2 已支持完整自动来源声明和可空的异常视觉清单，v1 及无包旧用法不变；声明本身不证明测试已经执行或原位置正确。实际合入的 40 项交接回归及 102 子测试通过。浏览器 9 项首轮测试、后加的截图数量兼容和失败范围反例、18 项相邻回归均通过；真实小样本验证了所选正文到未选文件的普通链接／注释往返和缺目标负例。

当前渐进能力缩小浏览器渲染范围，完整 EPUB 构建和静态包 QA 仍保留；EPUBCheck 单文档模式已实测正反例。全源码 Ruff 的 21 项既存问题在范围外；新浏览器测试 Ruff 通过。

## Review

独立合同核对发现范围报告混淆“已选失败”和“未选”。修复后分别记录 selected_members／unselected_members 与实际 checked／unchecked；同一反例及最终回执相关测试通过，blocking 已关闭。
