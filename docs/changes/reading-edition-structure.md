# 阅读版结构、前置页与翻译边界

## Status

implemented

## Problem

溯源标记可能侵入 Markdown 标题语法，与章节层级混淆；手工翻译目录与生成导航并存也会破坏唯一目录。既有全来源标记覆盖契约不能准确表达阅读版的排除、合并与重建，移动标记会伪造溯源。封面与来源设计身份也须单独核定。

## Scope

- 默认阅读版：保留著作内容、序跋、版权许可、参考文献、附录、作者简介和索引；排除纯出版广告、购买推广、旧设备通用说明，逐项记录依据。
- 原书可见目录与正文核定全书逻辑章节，来源文件边界仅作证据；先验证真实标题树，再翻译和生成唯一导航。
- 区分翻译、准确保留、功能重建和明确排除；不按重复字符串删除来源设计中的书名，不默认增补 metadata 书名页。
- 来源映射追加可选 disposition，表达 retain、merge、rebuild、exclude；旧映射继续完整覆盖，新映射不向无关正文搬移标记。
- 最小共享修复：阻断溯源标记吞并标题，允许显式关闭 EPUB 自动书名页并配置目录深度；保留旧调用默认值。必要时支持显式导入外部只读来源到新作品资产，不写 Books 或外部来源。
- 已发现的保真问题按原生语义修复：跨页完整代码块的来源页集合、彩色绑定来源的语义 Span 与非颜色区分、斜体中的局部正体；关闭作者样式仍保留阅读器基础图片适配与代码局部滚动，不放宽资源或全页溢出检查。
- 脚本采用隐藏子进程与复用会话，文件读写优先直接 API；统一 CLI、来源 Pandoc 与浏览器 runner 的 Windows 子进程不弹终端，不终止用户终端。
- 完成来源、结构与范围核定后先走通完整章节，再按来源顺序恢复、翻译和验收。封面保留设计身份、使用可编辑准确文字，不擅自复用受保护素材或出版标识。
- 使用工站记录与单书 STATUS 监控；首章闭环是内部验证点，记录经验后继续已授权工作。只有无法推进且需要用户介入时暂停受影响部分，其余独立工作继续。

## Acceptance Criteria

1. 规则明确阅读版范围、唯一目录、可选书名页、章节先行、翻译边界和检查点；参考事实能追溯到原生成员与实际渲染。
2. 匿名回归覆盖标记吞标题、新旧映射覆盖、无理由排除、书名页开关及目录深度；原调用默认行为不变。
3. 真实消费者恢复章节与分部父子关系，无独立静态旧目录；唯一受控书名页、封面、正文与导航实际渲染通过，本地候选完成必要机械验收。
4. 全书来源、版本、许可、结构与范围核定后，纳入内容完整恢复和翻译；代码、图表、语义及跨页边界通过独立审查，正式输出完整重建与验收；首章仅为内部验证点。
5. 触碰中文 Markdown 经 AutoCorrect，文档结构、聚焦回归与必要兼容性检查通过；一次独立 review 的 blocking 关闭。
6. 不修改 Books、范围外来源或用户配置，不自动提交或发布；仅在明确授权且全书完成后交付，不以试做或局部修复验收替代完成门槛。

## Result

已把阅读版范围、逻辑章节先行、唯一导航、受控书名页、翻译／保留／重建／排除边界及首章检查点写入事实所有者。只读来源参考表明文件边界不等于逻辑章节，来源设计中的分部／章首重复书名应保留。

共享构建器落实可选 disposition、书名页开关、目录深度、显式正文 landmark、标记／编号图的正式 AST 检查；保留旧入口默认契约。外部只读来源可显式导入新作品资产；真实 stdin AutoCorrect 不跳过私有稿件，并在写前保护代码／公式字面量。

真实消费者完成必要结构修复、正式构建与全量三模式验收。实际渲染纠正了 LineBlock 额外断行、专名 break-all、自动书名 H1 和大字图片自然宽度问题；阅读器基础图片适配不豁免横溢或内容检查。隐藏执行采用直接文件 API、复用 Node 会话和 Windows 无窗口子进程，不改用户环境或关闭用户终端。

来源页不能只按数量验收：新页顶部图、完整跨页程序的续页标记按原图绑定直接引导段，补充页集合不替代原生 marker。同基线前提按列恢复，Code 外多空格用 NBSP，完整 DOM 程序而非碎片库存用于检查字符保真。

保留 reader 基础适配时，用户正文仍用所选字体，代码及缩进保留等宽字体、原换行和局部横滚。原 HTML 大图与宽表也按真实父容器适配，不用隐藏全页溢出过关；默认生成的阅读器地标标签随中文包本地化。

## Review

- 共享实现独立 review 发现的兼容性、嵌套图片替代文本和真实 AutoCorrect 问题均修复并限定复验；最后的图片基础适配增量 review 无 blocking。全套 169 项回归通过，最后增量的 5 项浏览器 runner 聚焦回归通过。
- 真实消费者的目录、前置页、封面、图内信息、脚注、导航和正式输出经对应独立检查；来源误读经原页裁决，来源页锚点、闭包身份、配色边界和译意强度等发现逐项修复并定点读回。
- 隐藏启动、富代码行列、多色高亮和关闭作者样式的基础代码适配经独立限定 review；两套样式 × 三模式无整页横溢，局部横滚与线型区分反例修复后复验。非 Windows 隐藏启动分支只有静态兼容证据。
- 最新全套中 170 项及 66 个 subtest 通过，唯一失败为隐藏进程缺少 ImageMagick 的模块环境；按现有安装 manifest 仅补本次进程环境后，该单项通过。后续新增样式对比与浏览器 5 项聚焦回归通过。
- 地标标签与 HTML 媒体／表适配的独立限定 review 无 blocking；新增回归及文档／浏览器聚焦 36 项＋9 subtests、受影响 EPUB 兼容回归 29 项＋11 subtests 通过。中文 Markdown 的 AutoCorrect fix／lint、文档结构与 diff 空白检查通过。额外尝试的 Python black 未安装且无离线缓存，未执行该可选格式化。
