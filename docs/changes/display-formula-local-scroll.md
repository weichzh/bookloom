# 生成展示公式的局部横向滚动

## Status

implemented

## Problem

生成的长展示式在窄屏被 max-width 按页面宽度压缩，固定 em 高度仍占据较大空间，使公式笔画过小；200% 用户字号也可能被压回。无整页溢出不能证明公式可读。

## Scope

- 只对 .display-formula 语义容器中的 math-display 取消图片宽度压缩，以既有 em 相对尺寸和 SVG 原比例显示；容器限于正文宽，必要时自身横滚，短式无多余滚动。
- 来源公式图、信息图、普通图和行内公式仍按原策略拟合；不改来源、公式、alt、行数、编号或正文。
- 关闭出版社样式的基础规则采用相同生成展示式容器适配，用户字号继续生效；普通媒体的 max-width 100% 不变。
- mediaFittingApplied 只核普通媒体和未采用该语义容器的对象；mathDisplayScrollingApplied 单独核生成展示式的容器与图片规则，在含公式的读者模式结果中强制检查，不放宽全页溢出阈值。

## Acceptance Criteria

1. 真实长式在窄屏、深色、关闭出版社样式及出版社样式 200% 下保原比例和相对笔画尺寸；容器可滚到末号和末字符，页面本身无横向溢出。
2. 短式、行内式、普通图和未包装来源公式图保持各自契约；重复片段导航不丢相对尺寸或滚动能力。
3. 实际宽度缩回、裁切或适配字段失效的负控被拒；此前内容盒及源图衬底回归保持有效。
4. 只回补受影响消费者，不重新审正文／OCR；独立定点 review 关闭 blocking，文档及相关 diff 检查通过。

## Result

已在生产 CSS 和关闭出版社样式的基础规则中实现。真实长式在窄屏及 200% 字号下按相对尺寸显示，末字符和末号可滚到，页面横溢出为 0。

真实对象及独立自包含合成回归均覆盖三默认模式的 390／1280 两宽及出版社 200% 两宽，共各 8 布局，含 4 次片段往返及缩宽／隐藏滚动负控。回归位于 tests/test_display_formula_local_scroll.py；正式入口复用相同生产代码与合成输入的实际运行证据。

直接依赖检查：浏览器门禁／普通媒体对照等 8 passed、6 子例，内容盒及栅格／SVG 衬底／读者尺寸 3 passed。首轮 3 项因测试父目录未创建而未运行，修正后只执行这 3 项，不把 setup error 记为产品失败或通过。

## Review

独立 review 核对实际 CSS 优先级、两个分离的读者适配字段、原全页溢出阈值、真实与合成八布局及两项负控，无 blocking。
