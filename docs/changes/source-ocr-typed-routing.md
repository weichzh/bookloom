# 来源 OCR 的类型路由与有界实验

## Status

implemented

## Problem

把所有图页交模型目检成本高；把文档解析器重复用于已知窄公式也会漏切。仅有 OCR 成功、节点计数或多数投票不能检出原稿摘要、错符号、错格值和静默纠正原书。需要把已完成实验变成可执行的来源核验规则。

## Scope

仅更新 TRANSLATION 第 3 节的原生优先、类型路由、字段测试与实验顺序，并澄清公式内自然语言说明与数学／数据标识的翻译边界。不增加 OCR 平台、CLI、来源格式或自动放行开关，不安装更多模型，不改变原文、代码及既有生成引擎。

当前路由：文字／图内标签用 RapidOCR 的已知来源 ROI；公式用直接 PP-FormulaNet 而非窄式重跑 layout，Ovis 官方专用任务为定点替代；表格优先原生数据及精确格值／顺序／合并格核验，VLM 仅作恢复候选；代码优先版本匹配的作者源，保字面、物理原行及逻辑续行，不擅改拼写或 API。可靠原生 MathML、文字和嵌入资产不重复 OCR；先区分真实 painted 文本与隐藏 OCR 层。

## Acceptance Criteria

1. 原始输出、位置和转换保可追溯；给定 ROI 的识别与整页自主定位分开计量，置信度及模型投票不能独立放行。
2. DOE 按真实来源对象区组、随机处理次序和冻结条件；不同条件不冒充独立样本。先筛选、再用未运行对象确认选定路线；只重算计量错误，不重复确定性推理造样本。
3. 原生参考只覆盖其实际字段，未知金标单列；保护数字／否定／字体／装饰／脚本、表格身份及代码检索键，不能用通用 MathML 等价或删除字面差异凑通过。
4. 所有步骤沿用首次全量／中间模块依赖／最后一次全量和异常定点图像规则；纯 OCR 不相等不自动变成人工逐图待审队列。
5. 触碰文档 AutoCorrect 及结构检查、核对研究与实际消费、一次独立只读 review 后收口。

## Result

已把 12 对象 144 条件格筛选（138 次主推理）及 8 对象 16 次原生公式确认收敛到 TRANSLATION 第 3 节；规则只写来源条件／类型路由／字段与失败处理，不写通用准确率。公式独立自然语言说明与数学／数据身份的翻译边界已明确，代码内部字面原契约不变。实验只支持其来源与参考字段覆盖的结论。

## Review

独立只读检查确认实验数值一致、没有普适准确率夸大；发现两个 blocking：未保留原生 EPUB 公式图像例外、未对所有路线写明候选写稿／翻译前的校验。明确 PDF 适用域及 EPUB 例外，并补全来源绑定／适用内容结构校验和未覆盖字段处理后，两项关闭。触碰文档格式、长度及 diff 检查通过。
