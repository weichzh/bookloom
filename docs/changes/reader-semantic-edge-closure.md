# 原生诗行注释与显式宽表公式适配

## Status

implemented

属于用户已授权的共享缺陷收尾。

## Problem

教学颜色检查对所有 LineBlock 解析教学上下文，误把没有教学标记的普通诗歌 Note 当标题错误。显式 table-scroll 虽允许横滚，行内公式仍受普通段落 max-width 约束；固定相对高度与受限宽度组合会压扁公式。

## Scope

- LineBlock 仅在实际含教学 Span 时进入教学上下文检查，采用既有 Para／Header 适用条件；普通 Note、标题 Note、教学 Span 保真检查的其他契约不变。
- 仅在已声明 table-scroll 的原生 table 内取消数学图像宽度上限，保原相对尺寸及比例，利用既有容器横滚；普通公式、图片及未声明的表格保持原策略。
- EPUB 出版社样式及关闭出版社样式的基础规则覆盖同一语义条件；适配检查单独验证该例外，不放宽全页溢出阈值或图像加载检查。
- tools/epub_semantics.py、formats/epub/book.css、tools/epub_browser_qa.py 及必要测试和直接契约；不改正文、公式或原资产。

## Acceptance Criteria

1. 普通含 Note 的原生诗行可经真实 reader／writer 与静态 QA，注释唯一且回链完整；真正教学 Span 丢失或改变仍失败，旧标题 Note 默认条件保留。
2. 宽表中直接及段落内公式在窄屏、大字和三读者模式保原比例，末列可达，无整页横溢；普通媒体与未声明表的正常对照保持。
3. 缩宽或隐藏滚动负控被自动检查拒绝；复用既有浏览器及 pytest，不逐图审查。

## Result

普通诗歌／教学 Span／旧标题 Note 正反控及真实 EPUB writer、静态 QA、EPUBCheck 共 3 项通过；实际含原生注释的诗行模块也已消费，原引用／唯一注文／回链保持。

真实 39 表的完整来源 AST 展开包装后相等；三读者模式各 684 个表内数学图通过比例、数字保行、图像及全页宽度检查，另补 390px 深色条件。公式超出视口时分别核左右边缘可在可操作滚动位置到达，不要求宽于窗口的整图同时可见。合成公开回归覆盖直接／段首公式、普通媒体与未声明对照及缩宽／隐藏滚动负控，三模式均在 390px 消费。

## Review

主 Agent 已核实际选择器优先级、LineBlock 的适用条件、完整 AST 保全与生产等价 DOM 数据。新增例外只针对显式表内数学图；普通媒体拟合及真正教学语义错误仍受原检查。相关阻塞已关闭。
