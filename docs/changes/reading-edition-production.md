# 阅读版生产门禁、原页导航与可靠执行

## Status

implemented

## Problem

质量依赖合入后的人工补救：目录机器门禁只对照 ID 序列，富代码和跨页取证分散。隐藏父进程未解决 Windows 子进程弹窗；PDF 来源页缺少标准 page-list，已确认来源勘误也缺少读者可见入口。

## Scope

- 完整目录树门禁：顺序、层级、标签、ID、链接和实际目标对应；保持旧调用可用。
- 把普通／富代码全文、空白、缩进与高亮保全核对纳入共享构建／浏览器验收；来源集合及交接资产／术语／首尾锚点在合入前验证。
- 统一现有 CLI 与浏览器 runner 的隐藏执行、会话启停、取证和关闭；追踪并修复 Windows 子进程弹窗，不修改用户全局配置或终止无关进程，不以父进程参数／源码检查冒充无弹窗实测。
- 从已核定来源位置派生标准 pagebreak／page-list 与来源元数据，不强制分页；跨页代码必须定位真实续行，不能把 lead 上的范围元数据直接冒充精确页界。无可靠原页码的 EPUB 来源不虚构页码。
- 增加明确标识的读者勘误内容，区分原书问题和译稿修复，原文／代码不静默改写；已确认勘误从原页复核后纳入。
- 在浏览器实际检查目录、页码、脚注、长代码横滚与图片，保留既有三模式全 XHTML 门禁。
- 本次外部交付以获授权且已确认的既有目标为限，不创建目标文件夹。

## Acceptance Criteria

1. 新旧入口及必要 Adapter 回归通过；错误目录树、富代码失真、无效交接与不实来源集合的具体反例会失败。
2. 实际 headless 启动／操作／关闭期间有 Windows 窗口事件证据，相关启动链不出现可见终端；父／守护／浏览器层均明确定位，用户终端不受影响。
3. 已保留页产生真实可跳转的标准原页导航，跨页代码页界正确且代码字符不变；其他 Adapter 有代表回归，无可靠页码来源明确不适用。
4. 可核定原书勘误有读者可见入口，标识／范围／原文忠实性核验；唯一章节目录仍成立。
5. 浏览器实际读者路径和三模式全量机器检查通过，独立 review 的 blocking 关闭；按正式完成／交付契约核验。
6. 规则／契约与实际实现同步，触碰中文 Markdown 格式检查通过。

## Result

已落实到共享实现和标准流程：

- 完整标题树检查绑定 ID、标签、层级／父子、真实标题落点及 OPF spine／DOM 阅读顺序；自动编号按实际 writer 配置推导，旧接口保留。
- 普通／富代码全文、空白、缩进、高亮范围及代码外教学 Span 进入构建／QA；浏览器逐 XHTML 将实际 DOM 与同包静态规范记录比较。Code 内 NBSP 不再等同普通空格。
- 新 Markdown 分片以显式 handoff-check 校验来源集合／辅助集合、首尾、语言、资产、术语及核定负责人；没有交接声明的旧书不加前提。
- Windows 隐藏 runtime 托管隔离 Chromium，经标准 agent-browser CDP 操作并精确回收；持久窗口事件诊断器为 tools/windows_window_monitor.py，不修改全局安装或配置。
- 原页导航绑定实际代码容器；移动到同文本的另一程序也会失败，不拆程序或改变字符。已确认来源勘误以明确标识的编校内容提供读者入口，原作者程序忠实保留。
- 长代码由普通／富代码本地容器横滚并保原行；关闭作者样式时保用户字体、字号、图片等比适配，完整性检查不豁免。

真实消费者完成最终全量三模式和 EPUBCheck；实际读者路径另覆盖目录、代表性原页导航、勘误回链、图号链接和脚注往返，HTML 图像及代码 DOM 保全经检查。

原路径曾捕获 Chrome 子进程 PseudoConsoleWindow。修复后 5 个冷启动会话、一次启动超时及异常关闭通过，11 个精确句柄全部退出，guard 未受影响；真实读者会话与两次最终全量运行的终端事件均为 0，两个 hook 均成功安装。持久诊断器另有 11 项测试、4 个子例。

共享全套 270 项回归首次 268 项通过；两项初次失败定点关闭：旧 CSS 断言更新为已验收的原行／局部滚动合同，另一个是 mise 的 Node 后端元数据错误，使用现存 Node 24.1.0 进程级运行后通过，未改全局环境。最高证据为真实来源核定和生产等价本地／浏览器验收。

## Review

独立 review 关闭生产实现的 blocking：DOM 记录未参与判定、before-target 绕过代码行定位、同文本程序间页点漂移；另核对受控 LaTeX 编号、旧调用和局部滚动合同。来源核查促成辅助来源集合越界、正文标题逆序、Code 内 NBSP 失真三个反例修复。持久窗口诊断器的根 PID 复用归属问题补反例并经独立定点复验关闭，无剩余 blocking。
