# 数学图像的内容盒尺寸

## Status

implemented

## Problem

公式图片声明的 em 高度在共享 border-box 下包含衬底内边距，短式内容高度可能接近零。SVG 和 alt 完整、浏览器无溢出仍不能证明公式可读。

## Scope

公式 img 改为 content-box，声明 em 高度用于内容，最大宽度扣除相应内边距；保段首缩进预算、原生块图局部滚动、深色衬底和阅读器关闭出版社样式的原有尺寸适配。普通图、源 SVG、alt、TeX、正文和编号不变。

宽度约束时允许 SVG 默认等比绘制产生留白，不用 CSS 盒长宽比冒充实际笔画比例。本项不改变长公式的现有拟合／滚动策略；另有具体不可读对象时单独研究。

## Acceptance Criteria

- 短／高展示式及行内式的内容高度随声明 em 和用户字号缩放；旧 border-box 反例失败，普通图正常。
- 浅色、深色、关闭出版社样式及出版社样式下 200% 字号，390／1280 宽度无整页溢出；受宽度约束式的实际笔画保持比例，两端可达，原生块图仍局部横滚。
- 实际受影响 XHTML 消费，异常公式定点复核；按实际受影响范围处理 CSS 重建，不重新审正文或 OCR。
- 一次独立 review 无阻塞；中文文档格式及相关 diff 检查通过。

## Result

CSS 已改为内容盒并为行内／展示分别扣除 0.16em／0.7em；直接展示式选择器也覆盖原有容器规则，保留更高特异性的原生块图滚动。新几何正反控 1 passed、既有栅格／SVG 衬底及读者尺寸 2 passed。真实候选短式在 100%／200% 字号下按比例放大，无整页溢出，并经定点视觉复核。

实际消费者的 CSS 回补范围已按是否包含公式区分；目标路径缺失时须先核实真实目标。回补沿用既有底稿和内容证据，不重审正文或重跑 OCR。

## Review

独立 reviewer 对实际 CSS、宽度链、正反控与运行证据定点审查，无 blocking；原生块图的高特异性例外保留，普通图不受影响。
