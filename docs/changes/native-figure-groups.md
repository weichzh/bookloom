# 原生图组自动恢复与复核减负

## Status

implemented

用户已授权按全书实验结果优化，优先减少人工与 Agent 逐对象干预。

## Problem

现有候选流程把多图板当作独立图片；图注只在单个文本块内按字符串匹配，无法处理跨块数学字形及附录编号；分割阈值又被用于无损边界，漏掉浅灰抗锯齿像素。无候选页被一律列入复核，掩盖真正异常。

## Scope

- 在现有 source-figures 工站增加原生 PDF Form XObject 及 image 的完整图组恢复。使用已经安装的 pypdf；缺少该可选能力时明确记录，不改变既有运行条件或静默宣称已检查。
- 用原生调用、变换、裁剪和独立图注区域约束归组；保留全部模型 raw 身份，不能把模型局部框或白面板当语义边界。
- 恢复跨文本块、多行、数学字形和字母章号图注；不从源码金标读取候选位置。
- 分割核心和可见边缘分开，保留完整原生画布与有效浅灰边界，不放宽严格像素损失标准。
- 将无候选且无冲突的页作为机器信息，不制造逐页人工队列；未建立来源覆盖仍明确为未知。原生图组、局部残留、未配图注及真正歧义各给一个可执行问题。
- 保留 CLI、scratch 边界、verified=false 与既有模型 raw 复用。同源且渲染依赖有效时，逐文件核对后复用原页渲染及旋转信息；新增依赖只影响相关后处理，不强制重推有效 raw。

不修改书籍底稿、正式资产、manifest、STATUS 或 OneDrive；不新增模型、付费服务、外部样本、通用评测平台或长期缓存；提交推送另行授权。

## Acceptance Criteria

1. 复用已冻结整书自动基线与独立源码参考；开发阶段仅跑目标模块，冻结候选后跑一次全书评分及项目全量。来源、caption 身份和原页像素比较标准不变。
2. 同一作者 figure 的多图板形成一个完整对象及唯一完整图注；模型原始行全部可追溯，未被归组的候选不得丢失或假装已验证。原生变换、嵌套、裁剪、页级容器和多图多注歧义均有合成反例与正常对照。
3. 图体可见像素损失、caption／正文污染和实际裁图像素分别验证；严格损失为零，不以一像素容差消除失败。无来源证明时不得把无候选页当真负例。
4. 真书确认仍只使用用户既有来源；不以减少复核数字为由删除有效告警。报告归组量、可执行复核对象、无候选页、来源覆盖状态、推理复用及实际墙钟。人工／Agent 介入记录实际事件，未知 tokens／费用不估算。
5. 既有单体图、原生彩底、独立 legend、跨图注侵入、精确编号、原生 clip 及 artifact containment 的有效回归继续通过。依赖缺失或不支持的几何明确降为未知，而不是新前置条件破坏旧调用。
6. 更新唯一契约与必要流程说明，通过中文格式检查及一次独立 review，所有 blocking 关闭后收口。

## Result

已接入既有 source-figures 入口，无需新增命令参数。原生 Form 及真实 glyph／image 所有权恢复完整图组，模型原始行保留在 model_seeds；数学图注按完整原生行与有界字形转码对齐，记录未确立的提取器文本等价性，不修改原字形。

深色核心与 RGB 可见边缘分离；已知完整 Form 裁剪下的字形名义度量越界仅记信息，未知归属仍复核。review_summary 集中列可执行对象、工站／页失败与错误；无候选页只记信息，来源覆盖不因此改成通过。可选解析器仅绑定后处理，复用有效模型张量和逐文件核定的原页工件。

最终项目测试 1091 passed、27 skipped、365 subtests passed；关键重依赖 Form／图组／像素／逻辑用例已在配置环境单独通过。冻结私有来源已完成整书独立对象、viewport、严格可见像素、完整 caption glyph 身份及实际导出像素评分；具体来源、计数、时间与剩余异常保存在忽略的实验记录，不写入公共流程。

## Review

独立 review 已完成，blocking 全部关闭。已修复并定向复验旧 exact 调用条件、Form／region 与全部种子的一致性、未知弱墨迹及 RGB 边缘、工站／页级错误被内容告警遮挡等问题。真实确认对象另揭示副提取器数学转码和名义字体边界误报，均以保持原生 glyph 与完整可见内容为条件修复；额外正文、具体字母数字冲突、未知归属或不完整裁剪的拒绝反例继续通过。
