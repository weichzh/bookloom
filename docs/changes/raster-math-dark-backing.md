# 原生栅格公式的深色衬底

## Status

implemented

## Problem

深色模式中透明 PNG／GIF 公式的黑字若被放在深色衬底上会难以辨认；生成的主题感知 SVG 则需要保留原深色衬底。首版 CSS4 大小写标志被 EPUBCheck 的 CSS-008 拒绝，须使用兼容写法，不绕过检查。

## Scope

- formats/epub/book.css 的深色公式背景规则仅匹配 SVG 公式；栅格公式沿用既有白底。
- 增实际 CSS／浏览器／EPUBCheck 回归，覆盖透明 PNG、GIF 以及主题感知 SVG；核定行内、展示和题注内公式，保持资源、字符、尺寸与原有主题关系。
- EPUB 规则同步说明格式差异，不修改作者公式、图像像素、alt、书级公式图注或正文底色。

不反色、不重编码来源图、不把栅格公式转换成新公式，也不扩大成全书图像染色或放宽检查。关闭出版社样式的既有基础适配不因本项改动而增加新前提。

## Acceptance Criteria

1. 真实透明栅格公式在深色模式中清楚可读，行内／展示／题注内对象均保原资源与几何。
2. 浅色栅格显示不变，主题感知 SVG 的深色样式及背景保持，大小写扩展名正确处理。
3. 使用最终公共 CSS 的真实 fixture 通过浏览器检查与 EPUBCheck；不依赖诊断时临时注入。
4. 检查已有包是否有同类公式表示，按实际受影响范围决定必要复验，不无差别重做有效全矩阵。
5. 独立 review 无 blocking，真实候选消费后才可继续终态验收。

## Result

公共深色规则现仅覆盖 SVG 公式的八种扩展名大小写组合，使用 CSS3 属性选择器；PNG／GIF 等栅格沿用默认白底。图像像素、路径、替代文本、尺寸和普通图片背景未改。

tests/test_raster_math_backing.py 通过真实 Pandoc EPUB、项目 QA、官方 EPUBCheck 及三种浏览器模式：7 个公式图覆盖透明 PNG／GIF 行内、展示、原生题注与主题 SVG，另保普通图。默认与深色的几何一致，选择器正确区分小写／大写／混合 SVG 后缀；关闭出版社样式仍为既有基础适配。真实消费者的受影响公式局部三模式检查通过，资源与正文成员未改；这不代表内容的全书验收。

已检查的既有包只含 SVG 公式或无公式，未发现受本项改变的栅格公式表示；因此未对该受检集合重建。此结论不扩展到未检查的消费者。

另发现关闭出版社样式后，高 DPI 原生行内栅格图回到自然像素尺寸而偏大；这是既有尺寸适配缺口，不由本项背景规则引起，另作修复。

## Review

独立 reviewer 只读审查 CSS、真实 fixture、EPUBCheck、三模式渲染及实际受影响对象，无本项 blocking。图源及正文成员不变支持仅改变衬底；高 DPI 行内图尺寸是单独依赖。
