# EPUB 来源探查与信息保全

## Status

implemented

用户在研究结果明确第一轮范围后，以“那就开始吧”批准实施。

## Problem

研究时本书 42 条工站记录中有 11 次命令失败。来源入口把跨文件同名 ID 当作单入口障碍，尾注识别依赖命名；非空 Notes 子树可被丢弃，转换成功不能证明正文保全。继续按书增加修补会掩盖来源表达方式和共享能力之间的边界。

## Scope

- 独立来源探查：汇总全部 spine 单元的元素、class、显式语义、ID、链接、样式依赖及不支持项；不把 class 猜成内容语义。
- 来源身份使用文件路径与 ID；生成确定的目标 ID 和文档入口，重写选定范围内的链接，保留原始身份映射。
- 在有限转换器中保全明确尾注与回链正文，检测未消费正文及 Markdown 往返后的文字和明确标题／注释结构丢失。
- 统一 CLI 在转换失败前保留来源探查报告；同步契约、聚焦回归和完整现有测试。
- 不增加出版社专用规则、可执行书级 hook、新的正式底稿格式或生成引擎；本轮仍明确报告未支持的图表、MathML 与样式语义。来源、已交付书籍及权限配置不修改。

## Acceptance Criteria

1. 匿名样本先证明原有跨文件 ID、显式尾注、非空 Notes 正文和结构／文字丢失缺陷，再证明修复通过。
2. 不同文件同名 ID、文件入口链接、跨文件脚注及链接片段都能确定映射；缺失目标、同文件重复 ID、越界路径仍失败。
3. 未知结构在完整探查报告中可定位；不生成空内容来掩盖非空来源。转换草稿必须通过信息保全检查，仍标记未经视觉核定。
4. 本书只读回放：26 单元的已知结构、207 尾注、13 表格、9 MathML 可探查；已支持单元无正文丢失，不支持项明确留在报告中。
5. 聚焦测试、现有测试、文档检查、AutoCorrect 和 diff 检查通过；独立 review 的 blocking 关闭。

## Result

共享实现位于 `tools/epub_source.py` 与 `tools/translator.py`，匿名回归位于 `tests/test_epub_source.py`，报告持久化的 CLI seam 位于 `tests/test_workflow_reliability.py`。公共行为已同步到 CONTRACTS 与 TRANSLATION。没有修改来源、正式底稿、已交付 EPUB、生成引擎、权限或依赖；没有提交或推送。

- 初始六个回归先失败，修复后通过。真实回放又识别并修复尾注标题漏出、回链与块内容混合、空属性容器的错误围栏、标题内溯源标记导致 ID 丢失；均纳入匿名回归。
- 最终 `uv run python -m pytest -q`：152 passed、57 subtests passed，退出 0。直接 `uv run pytest` 在当前环境无法导入 `tools`，最终证据使用 Python 模块入口。文档结构检查、触碰文件 AutoCorrect fix／lint 与 `git diff --check` 均退出 0；仓库未配置额外 Markdown formatter。
- 真实 EPUB 来源探查：26 个单元、207 条尾注、13 个表格、9 个 MathML；49 个未支持子树为 27 figure、13 table、9 math。`source-probe` 返回 0；完整 `source-draft` 按预期返回 1，保留完整报告并报告阻塞，不写部分草稿。匿名 CLI seam 同时验证重复运行不覆盖旧草稿，以及失败后报告仍存在。
- 排除未支持单元后的只读回放：18 单元、88 条尾注、76 个原生标题、979 个位置映射通过文字／结构／锚点检查；4 条警告仅涉及纯标题单元的草稿溯源标记。来源 SHA-256 仍为 B4D6F361A2CFB6A18DC41EAE62E986939854248092840BAC90FD340C0C6BF700；已交付 EPUB 仍为 9D375FAD893F691602B2B135C7BB7A1ED770C0D3182713FC1A64EEE654E06BC7。

最高证据为真实来源的只读机器回放；本次不重新构建或视觉验收中文书，也不证明所有来源表达方式、阅读顺序或样式已自动保全。正文字符检查不能发现仅重新排序的错误；注释另有有序文字检查。复杂图表、MathML、独立显式脚注、包内 query 及样式解释继续作为研究边界。没有足够可比样本证明指导次数或耗时下降，也不承诺统一入口永不触发安全审核。

## Review

独立只读 reviewer 首轮报告四个 blocking：探查漏报上下文限制；文件身份丢失导致本地尾注误判；独立显式脚注被降级；部分 ID 有重写链接但无实际锚点。主 Agent 先复现，再修复并补回归。复验确认四项全部关闭，同时关闭包内 query 丢失候选；复验执行聚焦测试并回放真实来源，主 Agent 核对实际 diff 后执行最终完整测试。

后续只在研究证明可跨书复用时扩展共享转换能力；不为本书剩余结构加入专用规则。当前无未关闭 blocking，按 PROTOCOL 保留 implemented 记录供用户审阅，未授权提交。
